Getting started

Sign in with an approved account.

VR Inspector is an authenticated workspace; project data loads after sign-in.

Open or create a project.

Projects organize inspections, drawings, photos, findings, reports, and team members.

Create an inspection.

Use a clear inspection title, type, inspector name, and notes for the site walk.

Split the work by device.

Capture evidence quickly on mobile, then perform precise drawing review on desktop.

Recommended device split

Mobile phone: field work

  • Open the active inspection during the walkdown.
  • Use Capture Photo for site evidence.
  • Log findings with priority and location reference.
  • Use dictation where supported; type if voice input is unavailable.

Desktop/laptop: drawing work

  • Upload drawings from organized files.
  • Review PDFs page by page with Prev / Next.
  • Use zoom controls for detail review.
  • Place pins accurately on the current PDF page or raster drawing.
Current guidance: phone screens are best for field capture; desktop/laptop screens are best for multi-page PDFs, zoom, and precise pin placement.

Core workflows

Projects and inspections

  1. Open Projects and select the right job.
  2. Create or open an inspection for the site walk or discipline.
  3. Use the inspection screen for weather context, photos, findings, sign-off, and reports.

Photos and findings on mobile

  1. Tap Capture Photo to add a field image.
  2. Tap + Log Finding to document an issue.
  3. Move findings from open to in progress or resolved as work proceeds.

Drawings and pins on desktop

  1. Upload PNG, JPG/JPEG, SVG, or PDF drawings up to the current 50 MB limit.
  2. Open the drawing thumbnail. PDFs use the Block 8E PDF canvas viewer; raster drawings open as images.
  3. For PDFs, choose the page and zoom level first.
  4. Use + Add Pin, click the drawing, and select the correct status.

Field-to-office handoff

Field inspector on phone

Capture photos, log findings, and add location references during the site walk.

→

Office reviewer on desktop

Review drawings, navigate PDF pages, zoom, place pins, resolve/reopen findings, and generate reports.

Use consistent finding titles and location references so office reviewers can match site evidence to drawing locations.

Permissions and access

Sign-in is required. Project membership controls access to project information, drawings, pins, and collaboration features. Member invitations are managed from the project screen through Members.

Use the correct project: confirm the project name before uploading drawings, capturing inspection evidence, or inviting another team member.

Troubleshooting current behavior

PDF controls do not appear

PNG/JPG drawings intentionally open without PDF controls. Pin placement still works on raster images.

Samsung Chrome slows or crashes at 200% zoom

VR Inspector reduces PDF canvas memory pressure on mobile browsers, but desktop/laptop is still recommended for high-zoom PDF review.

Drawing upload fails

Confirm the file type is PNG, JPG/JPEG, SVG, or PDF and under 50 MB, and that you are signed in within the correct project.

Voice dictation is unavailable

Voice input depends on browser support. Use Chrome or Edge where supported, or type the finding description.

Using iPad or Safari

For the most consistent PDF canvas rendering, page navigation, zoom, and page-aware pin placement, use a current desktop version of Chrome or Edge.

Photo opens but has no detail action

Continue using photos as inspection evidence attachments and document the related finding.
